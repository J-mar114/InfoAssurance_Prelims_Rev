# IT2511 Information Assurance Reviewer

An interactive, browser-based reviewer and 30-item mock exam for wireless and mobile security.

## Topics covered

- Wireless standards, spread spectrum, Wi-Fi encryption, and authentication
- Rogue access points, honeypots, KRACK, jamming, and Aircrack-ng tools
- Bluetooth modes and attacks
- Mobile device, browser, SMS, network, and cloud threats
- iOS Keychain, Android rooting, MDM, remote wipe, and OWASP Mobile Top 10

## Run locally

Open `index.html` in a browser. No build step or installation is required.

## Publish with GitHub Pages

1. Upload the repository to GitHub.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, choose **GitHub Actions**.
4. Wait for the `Deploy to GitHub Pages` workflow to finish.

The site is static and works on GitHub Pages, Netlify, or any standard web host.

## Search visibility checklist

- Keep the repository public if you want search engines to crawl it.
- Add the deployed URL to Google Search Console and request indexing.
- Replace the placeholder URL in `sitemap.xml` with the final GitHub Pages URL before submitting it.
